# 🏋️‍♂️ FitNation - Gym Management Web Application

A dynamic Gym Website built using Django that allows users to register as gym members, contact the admin, and receive confirmation emails upon signup. The site includes features like custom login/signup, profile control, form validations, and email integration using Gmail SMTP.

## 📌 Features

- 📝 **User Registration** (with email confirmation)
- 🔐 **Login & Logout Authentication**
- 📬 **Contact Form** with timestamp
- 💳 **Membership Plan Registration**
- ✉️ **Email Notification** on signup using Gmail SMTP
- 🧑‍💼 Admin Panel for managing users and members
- 👁️ Profile-based navbar (Login/Signup or Profile Icon)
- 🎨 Clean UI using Bootstrap & custom CSS
- 📂 Organized Project Structure

---

## 🛠️ Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** SQLite (default Django DB)
- **Mail:** Gmail SMTP Server
